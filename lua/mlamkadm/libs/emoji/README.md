# Zenful Emoji Picker for Neovim
This is a simple and elegant Emoji picker for Neovim, designed to be easily accessible, searchable, and visually appealing. It allows users to quickly find and insert emojis into their text.
## Features
- **Easy Access**: Open the emoji picker with a simple keybinding.
- **Search Functionality**: Quickly search for emojis by name or keyword.
- **Visual Appeal**: Display emojis in a grid format for easy selection.
- **Customizable**: Allow users to customize the appearance and behavior of the picker.
